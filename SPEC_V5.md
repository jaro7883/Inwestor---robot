# SPEC V5

## Cel etapu
Zwiększyć codzienną użyteczność bez stawiania backendu.

## Dodane moduły
- alerty lokalne
- snapshoty rynku
- wykres trendu średniego score
- rebalancing suggestions
- eksport/import pełnego stanu

## Ograniczenie
Bez backendu nie da się mieć:
- prawdziwych pushy działających zawsze w tle,
- stabilnego własnego cache danych,
- pełnych historycznych wycen per aktywo.

## Następny sensowny etap
Backend + baza + scheduler + push.
