# Robot Inwestycyjny V2

Ta wersja działa jako statyczna PWA na GitHub Pages.

## Co nowego
- lepszy mobilny UI
- radar okazji z rankingiem
- rekomendacja alokacji na miesiąc
- live dla BTC, ETH i Fear & Greed
- ustawienia strategii zapisywane lokalnie

## Jak wrzucić na GitHub Pages
1. Utwórz repo publiczne.
2. Wrzuć wszystkie pliki z tego folderu.
3. W Settings -> Pages ustaw deploy z branch `main` i folder `/root`.
4. Otwórz link w Safari na iPhonie.
5. Wybierz `Dodaj do ekranu początkowego`.
